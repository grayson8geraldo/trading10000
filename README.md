# Crypto Futures Trading Bot — $100 to $10,000 Challenge

Автоматизированная торговая система для агрессивного роста капитала на криптовалютных фьючерсах.

> **ВНИМАНИЕ**: Эта система использует высокое кредитное плечо. Вы можете потерять весь депозит. Используйте только те деньги, которые готовы потерять полностью.

## Быстрый старт

### 1. Установка

```bash
pip install -r requirements.txt
cp .env.example .env
# Заполните .env вашими API ключами
```

### 2. Настройка биржи

Создайте API ключи на выбранной бирже:
- **Bybit**: https://www.bybit.com/ → API Management
- **Binance**: https://www.binance.com/ → API Management

Начните с **testnet** (TESTNET=true в .env) для тестирования!

### 3. Запуск

```bash
# Бэктест (проверка стратегий на исторических данных)
python main.py --mode backtest

# Одиночное сканирование рынка
python main.py --mode scan

# Paper trading (без реальных денег)
python main.py --mode paper

# Реальная торговля (ОСТОРОЖНО!)
python main.py --mode live

# С вебхуками TradingView
python main.py --mode webhook
```

## Стратегии

### 1. Scalp Momentum (5m/15m)
Быстрый скальпинг на моментуме. Ищет моменты, когда RSI восстанавливается из зоны перепроданности/перекупленности при подтверждении объёмом и MACD.

- **Вход Long**: RSI > 25 и растёт + EMA 9 > EMA 21 + объём > 1.5x + MACD ускоряется
- **Вход Short**: RSI < 75 и падает + EMA 9 < EMA 21 + объём > 1.5x + MACD замедляется
- **TP**: 1.5% | **SL**: 0.7% | **R:R**: ~2:1

### 2. Breakout Volume (15m)
Пробой уровней после консолидации. Использует Squeeze Momentum и ATR для определения целей.

- **Вход Long**: Цена пробивает сопротивление + объём > 2x + squeeze release
- **Вход Short**: Цена пробивает поддержку + объём > 2x + squeeze release
- **SL/TP**: Динамические через ATR (1.5x/3x ATR)

### 3. Trend Follow (1h)
Входы на откатах в трендовом рынке. EMA стек + ADX для подтверждения тренда.

- **Вход**: Откат к зоне EMA 9-21 при тренде (ADX > 25)
- **TP**: 4% | **SL**: 1.5%

### 4. Mean Reversion (15m)
Возврат к среднему от экстремумов Bollinger Bands с подтверждением RSI и свечных паттернов.

- **Вход Long**: Цена на нижней BB + RSI < 30 + бычья свеча
- **Вход Short**: Цена на верхней BB + RSI > 70 + медвежья свеча
- **TP**: 2% | **SL**: 1%

### 5. Swing (4h)
Среднесрочные позиции от уровней поддержки/сопротивления.

- **TP**: 6% | **SL**: 2.5%

## Система фаз роста капитала

Бот автоматически адаптирует риски при росте капитала:

| Фаза | Капитал | Плечо | Риск/сделка | Стратегии |
|------|---------|-------|-------------|-----------|
| 1 — Micro | $0-300 | до 50x | 5% | Скальп, Пробой |
| 2 — Growth | $300-1000 | до 30x | 4% | + Тренд |
| 3 — Acceleration | $1000-3000 | до 20x | 3% | + Возврат к среднему |
| 4 — Preservation | $3000+ | до 10x | 2% | Все стратегии |

## Управление рисками

- **Дневной лимит убытков**: 15% — торговля останавливается
- **Максимальная просадка**: 30% — торговля останавливается
- **Трейлинг стоп**: Активируется при +1.5% прибыли, трейл 0.5%
- **Break-even**: SL перемещается в безубыток при +1% прибыли
- **Жёсткий лимит**: Никогда не рисковать > 8% капитала на сделку

## TradingView интеграция

### Установка индикаторов

1. Откройте TradingView
2. Pine Editor → вставьте код из `tradingview/combined_strategy.pine`
3. "Add to Chart"
4. Настройте параметры под свои нужды

### Автоматические алерты

1. Настройте алерт на сигнал "Long Entry" или "Short Entry"
2. Webhook URL: `http://YOUR_SERVER:5000/webhook`
3. Формат сообщения (автоматически заполняется):

```json
{
  "secret": "your_webhook_secret",
  "symbol": "{{ticker}}",
  "side": "buy",
  "action": "open",
  "price": {{close}},
  "strategy": "tv_combined",
  "message": "Long signal"
}
```

## Ручная торговля с индикаторами

Если вы предпочитаете торговать вручную, используйте индикаторы TradingView:

1. **combined_strategy.pine** — показывает сигналы LONG/SHORT прямо на графике с уровнями SL/TP
2. **scalp_dashboard.pine** — мульти-таймфрейм дашборд со скорингом (от -6 до +6)

**Правила ручной торговли**:
- Входите только при score >= 3 (лонг) или <= -3 (шорт)
- Всегда ставьте стоп-лосс
- Не рискуйте более 5% на сделку
- Максимум 2-3 сделки одновременно
- Не торгуйте против тренда на старшем ТФ

## Математика роста

Для достижения $10,000 из $100 за 30 дней:
- Необходимый дневной рост: ~16.6% (compound)
- Или ~3-5 успешных сделок в день с плечом 20-50x и TP 1.5-2%
- С учётом винрейта 55-60% и R:R 2:1

Это **крайне агрессивная** цель. Реалистично ожидать:
- При хорошем рынке: 500-2000% за месяц возможно
- При среднем рынке: 100-500%
- При плохом рынке: потеря части или всего депозита

## Важные советы

1. **Начните с testnet** — протестируйте систему без реальных денег
2. **Запустите бэктест** — проверьте стратегии на исторических данных
3. **Не торгуйте против тренда** — следуйте за рынком
4. **Соблюдайте дисциплину** — не отменяйте стоп-лоссы
5. **Не торгуйте на эмоциях** — после серии убытков сделайте паузу
6. **Ведите журнал** — trades.csv автоматически записывает все сделки
